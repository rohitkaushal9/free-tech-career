# 📱 Mobile App Developer (React Native)

**Kaam:** phone apps banana. React Native se **ek hi code** se Android aur iPhone, dono ke apps bante hain. Bahut si badi companies apne apps isi se banati hain.

**Kyun React Native:** agar aap JavaScript/React seekhte ho, toh wahi skill web aur mobile dono mein kaam aati hai.

## Raasta (order mein)

| Step | Kya seekhna hai | Free mein kahan se | Is step ka project |
|---|---|---|---|
| 1 | **JavaScript** | [roadmap.sh/javascript](https://roadmap.sh/javascript) | Chhote browser programs |
| 2 | **TypeScript:** JavaScript, galtiyan pakadne ke saath | [roadmap.sh/typescript](https://roadmap.sh/typescript) | Pichhle programs TypeScript mein |
| 3 | **React:** screens ko components mein todna | [react.dev/learn](https://react.dev/learn) | Ek chhota web app |
| 4 | **React Native + Expo:** pehla phone app, apne phone pe chalake | [Expo tutorial](https://docs.expo.dev/tutorial/introduction/) + [React Native docs](https://reactnative.dev/docs/getting-started) | Expo tutorial wala app, apne phone pe |
| 5 | **Navigation, data, API:** kai screens, internet se data | [roadmap.sh/react-native](https://roadmap.sh/react-native) | News ya cricket score app |
| 6 | **Git aur GitHub** | [roadmap.sh/git-github](https://roadmap.sh/git-github) | Saare apps GitHub pe |

## Galtiyan jo time barbaad karti hain

- JavaScript ke bina seedha React Native pe kood jaana. Pehle step 1 aur 2 pakke karo.
- Bahut bada app soch ke kabhi poora na karna. Chhota app poora karo.
- Sirf emulator pe chalana. Expo Go se apne phone pe chala ke dekho.
