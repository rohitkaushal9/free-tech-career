# 🛠️ Pehla project kya banaun, aur dikhaun kaise?

**Todo app sab banate hain.** Usse aap baaki logon se alag nahi dikhte. Project wahi banao jo kisi **asli problem** ko solve kare: apne ghar, mohalle ya college ki.

## Har track ke 5 real project ideas

### 🌐 Web (TypeScript, React, Next.js)
1. **College fest ki website:** events, timings, register button
2. **Hostel room-mate finder:** branch, city, sone ka time daalo, match dekho
3. **Apne mohalle ki lost & found board**
4. **Personal portfolio:** aap kaun ho, projects, contact (sabse pehla project yahi)
5. **Exam countdown + syllabus tracker** apni class ke liye

### 📱 Mobile (React Native + Expo)
1. **Hostel mess menu app:** aaj kya bana hai, rating do
2. **Bus / shuttle timing app** apne college route ke liye
3. **Daily habit tracker:** paani, padhai, exercise
4. **Shared expense app:** trip pe kisne kitna diya
5. **Attendance calculator:** kitni class aur miss kar sakte ho

### 📊 Data (SQL, Python, Power BI / Looker Studio)
1. **Apne ghar ke kharche ka dashboard:** mahine ka hisaab, category wise
2. **Cricket data analysis:** kis venue pe kaunsi team zyada jeetti hai (free datasets: [Kaggle](https://www.kaggle.com/datasets))
3. **Apne shehar ka mausam vs bijli ka bill**
4. **College result analysis:** kaunsa subject sabse mushkil
5. **YouTube / Instagram apne account ka analysis:** kaunsi post chali, kyun

### 🤖 AI Engineer (Python, LLM APIs)
1. **College notes chatbot:** apne PDF notes se sawaal-jawab
2. **Resume reviewer:** resume daalo, AI sudhaar bataye
3. **Hindi/Hinglish customer reply bot** kisi chhote business ke FAQ ke liye
4. **Meeting/lecture summary tool:** audio se notes
5. **Job description vs resume match score**

## Ban gaya. Ab dikhao kaise? 3 step

| Step | Kya karna hai | Free mein kahan |
|---|---|---|
| 1. **Push** | Code GitHub pe daalo. Har din ek chhota commit, taaki profile pe hare dabbe (contribution graph) bharein | [GitHub contribution graph](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/managing-contribution-settings-on-your-profile/viewing-contributions-on-your-profile) |
| 2. **Deploy** | Project ko live link do, taaki koi bhi phone pe khol sake | Web: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) ya [Vercel Hobby](https://vercel.com/docs/plans/hobby) · Data: [Streamlit Community Cloud](https://docs.streamlit.io/deploy/streamlit-community-cloud) · AI: [Hugging Face Spaces](https://huggingface.co/docs/hub/spaces-overview) |
| 3. **README** | Project kya karta hai, ek screenshot, live link, aur kaise chalaye | [About READMEs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) · [Profile README](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme) |

**Dhyaan do:** Vercel ka free Hobby plan sirf personal, non-commercial projects ke liye hai. Kisi dukaan ya client ka kaam karoge toh unka plan alag hoga.
