# 📄 Resume aur apply: 50 jagah apply kiya, reply kyun nahi?

Aksar resume kisi insaan tak pahunchta hi nahi. Bahut si companies pehle **ATS** (Applicant Tracking System) software se resume filter karti hain, aur kuch rules pe seedha reject bhi ho jaata hai.

## 1. ATS-friendly resume: checklist

- **1 page.** Fresher ke liye ek page kaafi hai.
- **Google Docs (ya Word) mein banao, PDF mein bhejo.** Design tools aur rangeen templates se bacho.
- **Simple font:** Arial, Calibri ya Garamond. Kam se kam 10 pt.
- **Header/footer mein kuch nahi.** Naam, phone, email, GitHub, LinkedIn: sab page ke andar.
- **Section ke naam seedhe:** Education, Skills, Projects, Experience. Headings mein symbols nahi.
- **Plain text test:** poora resume copy karke ek plain text file mein paste karo. Agar sab padha ja raha hai, toh ATS bhi padh lega.
- **Job description ke keywords** (jaise React, SQL, Python): sirf wahi likho jo aapko sach mein aate hain. Keyword bharna (stuffing) mat karo.

## 2. Project kaise likhein: formula

> **Kya banaya + kaise (tech) + nateeja (number)**

Example:
- ❌ "Made a college fest website."
- ✅ "Built the college fest website in Next.js with online registration; 300 students registered in the first week."

- Kam se kam **2 projects**, har project ke naam pe **GitHub ya live link**.
- Thode best kaam, bahut saare average kaam se behtar.

## 3. Referral: 50 random applications se behtar

LinkedIn pe us company ke kisi engineer ko chhota, izzat wala message:

```
Hi [Name], I'm [your name], a [final year / fresher] [track] developer.
I saw the [role] opening at [company] and built [project] that is close to this work: [live link].
If you think my profile fits, would you be open to referring me? Resume attached. Thank you for your time!
```

- Message chhota rakho, project ka link zaroor do.
- Ek din mein 5 achhe messages, 50 copy-paste se behtar.
- Reply na aaye toh ek hafte baad ek baar politely follow up, bas.
