# Free Tech Career 🚀

**Tech job chahiye, par course ke liye lakhon nahi hain? Yahan sab free hai.**

Yeh guide Indian students aur freshers ke liye hai jo coding, AI ya data mein career banana chahte hain, bina mehnge course ke. Har role ke liye ek seedha raasta: **kya padhna hai, kis order mein, aur kahan se free mein.**

Banaya hai [@roheit.ai](https://www.instagram.com/roheit.ai/) ne, "Dadaji ke Sawaal" series ke saath. Har naye reel ke saath yahan naya section judega.

## Kaunsi job chahiye? Apna role chuno

| Role | Kya karta hai | Guide |
|---|---|---|
| 🌐 **Web Developer** | Websites aur web apps banata hai | [Raasta dekho](roles/web-developer.md) |
| 🤖 **AI Engineer** | AI wale apps banata hai (chatbot, smart search, AI tools) | [Raasta dekho](roles/ai-engineer.md) |
| 📊 **Data Analyst** | Data se business ke sawaalon ke jawab aur dashboards banata hai | [Raasta dekho](roles/data-analyst.md) |
| 📱 **Mobile App Developer** | React Native se ek code mein Android aur iPhone apps banata hai | [Raasta dekho](roles/mobile-app-developer.md) |

Pakka nahi ki kaunsa role? [Kaunsa role mere liye?](roles/choose-a-role.md) padho.

## Kaise use karein

1. Ek role chuno. Do role ek saath shuru mat karo.
2. Uski guide ke steps **order mein** karo. Agla step tab, jab pichhla project bana lo.
3. Har step ke baad ek chhota project banao aur GitHub pe daalo. Job mein certificate se zyada aapke project dekhe jaate hain.
4. Atak jao toh Instagram pe [@roheit.ai](https://www.instagram.com/roheit.ai/) ke reel pe comment karo.
